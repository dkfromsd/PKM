# 🌐 Web Application Source
This directory contains the core source code for the web application projects associated with the vault.

## Contents
- `index.html`, `index_en.html`, `index_ko.html`: Main entry points for the web interface (multilingual support).
- `style.css`: Global styles for the web interface.

## Purpose
This folder serves as the build source for the frontend application deployed as part of the Gobi workspace ecosystem.
