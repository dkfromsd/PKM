# 🤖 StockBot Dashboard
자동화된 금융 분석 리포트, 데이터 수집 및 분석 에이전트, 분석 결과 관리 허브.

## 프로젝트 구조
- `Stock_Agent/`: 자동화된 주식 분석을 위한 스크립트 및 에이전트 모델.
- `Stock_input/`: 원본 시장 데이터 및 시장 스냅샷 수집 공간.
- `Stock_output/`: 처리된 분석 리포트 및 전략 요약본 저장소.
